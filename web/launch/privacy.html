Privacy policy

Visual Dynamics does not collect user data. There are no accounts, no usage statistics and no crash reports, and your projects and measurements never leave your computer unless you send them somewhere yourself.

The program

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The one request it can make is File → Check for Updates…, and only when you choose it from the menu. It reads visualdynamics.org/latest.json, and the only thing it says about itself is its version, in the request's user agent (VisualDynamics/0.1.0a14, for example). Like any web request, it reaches the site's host from your IP address. Nothing about you, your machine or your data is sent, and the program keeps no record of the check.

This website

The site is static pages served by Cloudflare Pages. It sets no cookies and runs no analytics or tracking scripts. Cloudflare, as the host, processes the ordinary connection details of each visit (IP address, browser, the page asked for) to deliver and protect the site, under its own privacy policy.

Downloads, source code, bug reports and feature requests live on GitHub, and the Python package on PyPI; visiting those pages is covered by GitHub's and PyPI's privacy policies.

Email

Mail to contact@visualdynamics.org is read by the author and used only to answer it. It is not shared or added to any list.

Changes

If this ever changes, this page will say so before the program or the site does anything different. Last updated September 28, 2026.
