Privacy policy

Visual Dynamics does not collect user data. There are no accounts, no usage statistics and no crash reports, and your projects and measurements stay on your computer unless you send them somewhere yourself.

The program

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

The only request it makes is File → Check for Updates…, and only when you choose it from the menu. There is no check at startup. On Windows and Linux, and for a pip install, the check reads visualdynamics.org/latest.json. The packaged macOS app uses Sparkle instead: it reads the list of updates attached to the newest release on GitHub, and downloads the update from GitHub only if you choose to install it. Sparkle's automatic checks and its system profile are both off.

The only information either request sends about the program is its name and version, in the user agent (VisualDynamics/ followed by the version number; on macOS, Visual Dynamics/ and the version, followed by Sparkle's own version). Like any web request, it reaches the host from your IP address. Nothing about you, your machine or your data is sent, and the program keeps no record of the check.

This website

The site is served by Cloudflare Pages. It sets no cookies and runs no analytics or tracking scripts. Cloudflare, as the host, processes the ordinary connection details of each visit (IP address, browser, the page requested) to deliver and protect the site, under its own privacy policy.

Two pages load information from GitHub. The downloads page asks GitHub's API, from your browser, which files the newest release carries, so that visit also reaches GitHub. The feature requests page gets its ranking from a small function on this site, which asks GitHub on the site's behalf; your browser does not contact GitHub for it.

Downloads, updates, source code, bug reports and feature requests are hosted on GitHub, and the Python package on PyPI; requests to them and visits there are covered by GitHub's and PyPI's privacy policies.

Email

Mail to contact@visualdynamics.org is read by the author and used only to answer it. It is not shared or added to any list.

Changes

If this policy changes, this page will say so before the program or the site does anything different. Last updated October 13, 2026.
